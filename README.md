AI Document Summarizer

Aplicação em Python para sumarização e extração de insights de textos longos utilizando a API do Google Gemini.

 📝 Problema Resolvido
Processar grandes volumes de texto ou relatórios manualmente consome tempo. Este projeto automatiza a leitura e gera resumos estruturados com pontos chave em poucos segundos.

 🛠️ Tecnologias Utilizadas
- **Python 3.10+**
- **Google GenAI SDK** (`google-genai`)
- **Python-dotenv** (Gestão de variáveis de ambiente)

 🚀 Instruções de Instalação e Execução

 Pré-requisitos
- Python instalado
- Chave de API do Gemini (`GEMINI_API_KEY`)
 Passo a Passo
