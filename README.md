# menu-de-registros
Menu de Registros (Portugol)  Programa em Portugol que mostra um menu com 4 opções (inserir, consultar, excluir e sair) e repete até o usuário escolher "Sair".   O que usei - Laço `faca...enquanto` - Estrutura `se / senao se / senao`  Próximos passos - Guardar os registros em um vetor
